## 原生、住宅、家宽、双ISP：四个词差在哪，你该买哪一种

四个词说的是四件事，混着用最容易买错。

**原生 IP**：IP 的注册归属地和机房物理位置一致，注册地就是当地。这是基础门槛，很多便宜套餐停在这一档。

**住宅 IP**：地址来自 ISP 分配给家庭用户的池子，不是数据中心段。TikTok 的风控会看 ASN 类型，机房段一眼能认出来，住宅段看起来就是普通宽带。

**静态家宽 IPv4**：固定不变的住宅 IP。合同期内地址不换，适合长期养号和稳定直播。动态住宅 IP 会按会话或周期轮换，登录地频繁跳变本身就是一个异常信号。

**双 ISP 家宽 IP**：IP 注册 ISP 和实际承载 ISP 分离，伪装层级最高，也是目前各家里报价最贵的一档。

纯净度和价格大致同序：双 ISP 家宽 > 静态家宽 / 住宅 > 普通原生 > 机房 IP。

对 TikTok 来说，静态住宅、动态住宅、机房三类的差别可以压成一张表：

| 对比维度 | 静态住宅 IP | 动态住宅 IP | 机房 IP |
| --- | --- | --- | --- |
| 地址是否固定 | 合同期内固定 | 按会话或周期轮换 | 固定，但 ASN 易识别 |
| 归属地可信度 | 高，真实 ISP | 高，真实 ISP | 低，数据中心段 |
| 养号 | 适合 | 短期可用，长期要管 | 风险高 |
| 直播 / 广告投放 | 推荐 | 不推荐 | 不推荐 |
| 主要用途 | 账号长期运营 | 采集、短期测试 | 建站、技术测试 |

**下单前要看清楚的一件事**：英国 AUD$8.90 那款，各渠道对它的标注并不一致。有的列表写成原生家宽 IPv4，也有的明确标成 Native IPv4、非住宅；德国、日本、台湾同样是原生 IPv4 口径。马来西亚那一档标注的是 Hosting IP。养号用原生 IP 够用，但如果你要做直播、对 IP 属性要求高，就别在 $8.90 这档上赌，直接选套餐页明确写 Residential 或 Dual-ISP 的型号。套餐页写 Native IPv4 还是 Native Residential IPv4，一字之差是两个东西。

## 一个静态 IP 能绑几个号？先把硬成本算出来

安全基线是一个静态住宅 IP 只绑一个 TikTok 账号。

原因不复杂。几个号从同一个出口登录、发内容、互动，平台会把它们归到同一来源，其中一个出问题，连带处理的概率很高，还可能被判定成工作室群控。风险大致是这样分布的：1 个账号属于标准配置，平台视为独立真实用户；2–3 个号短期可能不被发现，但关联隐患一直存在；4 个以上基本就是群控特征，封号只是时间问题。

也有不同口径。有服务商在自家 FAQ 里写「一个 IP 最多对应 1 个直播账号，养号可以适当宽松到 3 个以内」。这是商家自己的经验说法，不是平台规则，也没有官方文档支持，直播场景下他们自己也建议一台机器配一个主播号。你可以把它当成风险偏好的选择，但别当成安全线。

按一 IP 一号算成本就很直白了：5 个账号就是 5 台机器、5 个 IP。用英国 AUD$8.90 这档，5 台是 AUD$44.50/月；用 WePCMON90 九折大约 AUD$40/月；走年付八折，折到每台每月约 AUD$7.12。这是按标价做的算术，实际金额和折扣是否生效，结账页会给出结果。想靠「一台机器挂三个号」省下来的钱，本质是在拿账号存活率换，值不值自己判断。

## 买到之后：五步把环境配到不像异常

1. **先定账号面向哪个国家**。TikTok 会按 IP 归属地做本地化推荐，IP 和账号定位错位，冷启动流量就不准。
2. **买到连接信息**。通常包含 IP、端口、用户名、密码，保存好，别外传。
3. **在指纹浏览器里新建独立环境**，代理协议选 SOCKS5 或 HTTP，把四项信息填进去，再单独设这个环境的时区、语言、分辨率，跟 IP 归属地对齐。
4. **打开 IP 检测站核对**。确认显示的地区和运营商与购买信息一致，再检查 DNS 和 WebRTC 有没有泄漏真实地址，时区语言不匹配就回去改。
5. **固定环境后登录**，之后保持同一浏览器环境、同一 IP，发布时间和互动频率也别忽高忽低。

一个号一套环境一个 IP，配好之后别中途换。静态 IP 的价值就在「不变」，换一次等于把账号的网络身份重置，前面攒的信任打折扣。
